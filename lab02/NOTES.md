GitHub — это веб-сервис (платформа) для хранения репозиториев и совместной работы.


git diff и git diff --staged
Эти команды показывают различия, но между разными слоями состояния файлов.

git diff (до git add)
Сравнивает:

Рабочая папка <-> Последний коммит.

git status
Показывает текущее состояние репозитория

git diff
Сравнивает рабочую папку с последним коммитом и показывает изменения, которые ещё не добавлены в индекс.

git diff --staged
Сравнивает индекс с последним коммитом и показывает, что точно попадёт в следующий коммит.

Ветка — это указатель на коммит, позволяющий вести параллельную разработку. При новом коммите указатель ветки сдвигается на него, а слияние объединяет изменения из одной ветки в другую, создавая коммит с двумя родителями.
